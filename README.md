## Descrição dos 12 Desafios e Padrões Implementados

Este repositório documenta a implementação e refatoração baseada nos 12 desafios práticos utilizando Padrões de Projeto:

1. *Singleton:* Garantia de instância única para o gerenciamento de configurações globais do sistema (ConfiguracaoSistema).
2. *Factory Method:* Desacoplamento da criação de objetos de notificação (NotificacaoEmail, NotificacaoSMS via FabricaNotificacao).
3. *Abstract Factory:* Criação de famílias de objetos relacionados sem expor suas classes concretas.
4. *Builder:* Construção de objetos complexos passo a passo com validações.
5. *Prototype:* Clonagem de objetos existentes para otimizar a criação de instâncias repetitivas.
6. *Adapter:* Adaptação de interfaces incompatíveis para permitir a comunicação entre sistemas legados e novos.
7. *Composite:* Organização de estruturas de objetos em árvore (partes-todo).
8. *Decorator:* Adição dinâmica de responsabilidades a um objeto em tempo de execução.
9. *Facade:* Fornecimento de uma interface unificada para um conjunto de interfaces complexas de um subsistema.
10. *Strategy:* Definição de uma família de algoritmos encapsulados permitindo que intercambiem entre si.
11. *Observer:* Notificação automática de múltiplos objetos dependentes sobre mudanças de estado.
12. *State:* Alteração do comportamento de um objeto quando o seu estado interno muda.
